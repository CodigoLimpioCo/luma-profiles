# Contribuir

Gracias por mejorar Luma Profiles.

1. Crea una rama desde `main`.
2. Mantén los cambios pequeños y explica el comportamiento observable.
3. Ejecuta `dotnet build src/LumaProfiles/LumaProfiles.csproj -c Release`.
4. Prueba los cambios con al menos un monitor DDC/CI o documenta cuando no haya hardware disponible.
5. Abre un pull request con capturas para cualquier cambio de interfaz.

No agregues telemetría, publicidad ni acceso de red sin una discusión pública previa.
