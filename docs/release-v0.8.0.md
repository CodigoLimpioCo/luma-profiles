## Novedades

- Nueva categoría **Pantallas VA** con 10 modos pensados para paneles VA económicos (22" FHD 120 Hz): equilibrado, sombras abiertas, gaming 120 Hz, competitivo, cine, oficina, lectura, nocturno, corregir azulado y color vivo. La biblioteca pasa a 60 perfiles.
- **Punto de restauración reforzado**: se guarda al primer arranque, antes de cualquier cambio, y además en `restore-point.json`, que se recupera solo si `settings.json` se daña. Se puede reemplazar desde Configuración > Datos ("Guardar estado actual", con confirmación).
- Restaurar devuelve la gamma neutra de Windows en pantallas cuyo estado no se pudo leer.
- Menú lateral con ancho ajustable (arrastrando el borde o con el teclado).
- Los idiomas incluidos funcionan aunque la carpeta `Locales` no se pueda escribir (ejecutable portátil en ubicaciones de solo lectura).
- Incluye ejecutable portátil y paquete ZIP para Windows x64.
