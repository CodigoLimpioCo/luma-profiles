## Novedades

- **Color de acento a tu gusto**: la paleta pasa de 6 a 17 colores y hay una opción **Tu color** para crear el tuyo con tres controles (tono, intensidad y brillo) o escribiendo un código `#RRGGBB`. Los textos se ajustan solos para que se lean bien en el tema claro y en el oscuro, y el texto de los botones pasa a blanco cuando el acento es oscuro.
- **Campos de texto corregidos**: el cursor ya no queda desplazado ni se solapa con el texto de ayuda al escribir.
- Requiere Windows 10 versión 2004 (build 19041) o posterior.
- Incluye ejecutable portátil y paquete ZIP para Windows x64.
